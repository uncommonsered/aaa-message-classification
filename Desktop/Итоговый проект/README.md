# Классификация сообщений мессенджера Авито

Проект по автоматической классификации сообщений мессенджера на 5 классов и
ограничению нежелательного контента.

**Классы:**

| Класс | Описание |
|---|---|
| `normal` | Обычное сообщение по сделке |
| `external` | Попытка увести общение с платформы (телефон, мессенджеры) |
| `spam` | Спам / реклама |
| `harassment` | Оскорбление, токсичность без прямой угрозы |
| `threat` | Прямая угроза физической расправой адресату |

## Порядок выполнения работы

Ноутбуки запускаются строго по порядку: каждый опирается на результат предыдущего.

```
01 ─► 02 ─► 03 ─► 04 ─► 05 ─► 06
EDA   аугмен- углуб- аудит  LLM-   обучение
+     тация   лённый regex  раз-   модели
подго-        EDA           метка
товка
```

| Этап | Ноутбук | Модуль | Что делает |
|---|---|---|---|
| 1 | `01_eda_and_data_prep.ipynb` | `src/data_prep.py` | Загрузка сырых данных, диагностика качества, очистка, фичи, разбивка train/val/test |
| 2 | `02_data_augmentation.ipynb` | `src/augment.py` | Добавление внешних источников (AlexSham, ru_paradetox), regex-разметка threat/harassment |
| 3 | `03_deep_eda.ipynb` | `src/deep_eda_plots.py` | Углублённый анализ: длины, сигнальные признаки, частоты слов, сравнение доменов, риски |
| 4 | `04_regex_audit.ipynb` | — | Аудит качества `DIRECT_THREAT_RE`: recall/precision, ложные срабатывания и пропуски, regex v2 |
| 5 | `05_llm_labeling.ipynb` | `src/llm_labeling.py` | Zero-shot NLI разметка 500 примеров AlexSham для поиска скрытых угроз |
| 6 | `06_model_training.ipynb` | — | Обучение классификатора: бейзлайн TF-IDF + LogReg и fine-tune `rubert-tiny2`, метрики и латентность (запуск на Kaggle GPU) |

## Ключевые выводы

1. **Класс `threat` критически недопредставлен** (279 примеров, 0.07%) — при обучении
   обязателен oversampling или взвешивание классов.
2. **Regex `DIRECT_THREAT_RE`** даёт высокую точность (~85–90%), но очень низкое
   покрытие (recall ~0.51% токсичных) — большинство угроз уходит в `harassment`.
3. **LLM zero-shot разметка** (этап 5) показала, что AlexSham — это в основном
   оскорбления, а не личные угрозы: из 500 примеров лишь 3 (0.6%) оказались
   реальными прямыми угрозами адресату. Это объясняет низкий recall regex и
   указывает на необходимость других источников угроз / синтетической генерации.

## Воспроизведение

```bash
pip install pandas numpy matplotlib scikit-learn datasets transformers
```

Положить исходные CSV в `data/`, затем запустить ноутбуки по порядку `01 → 05`.
Внешние датасеты (AlexSham, ru_paradetox) скачиваются автоматически с HuggingFace
при первом запуске этапа 2. Модель для этапа 5 (`mDeBERTa-v3-base-mnli-xnli`, ~1.2 ГБ)
скачивается локально, API-ключи не требуются.
